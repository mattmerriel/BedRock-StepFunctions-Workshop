# Follow the AWS Instructions
Rather than invent the wheel here, I'm going to direct you to the offical AWS documentation on how to install the CLI.

if you can run the following command
``` 
aws --version
```

and get back something that looks like this
```
aws-cli/2.16.3 Python/3.11.8 Darwin/24.1.0 exe/x86_64
```

Then you already have the AWS CLI installed on your machine and can process to installing the AWS SAM CLI by clicking [here](Install-AWS-SAM.md). 

If you get back an error or not found message, follow the instructions on the AWS site [Installing or updating to the latest version of the AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) to get yourself setup. Once you can successfully run the cli, you can move onto the [next part](Install-AWS-SAM.md)
